# QuantFlow — 移动端量化交易自动化平台

## 产品定位

一站式移动端**智能**量化交易管理工具，支持 **币安（Binance）** 和 **MT4/MT5** 两大交易生态，内置 **大模型 AI 引擎**，实现策略自动生成、实时市场分析、策略自进化和风险预判。

> 📖 AI 引擎详细设计见 [AI_ENGINE.md](./AI_ENGINE.md)

---

## 核心功能模块

### 1. 📊 策略管理
- **策略市场**：内置经典策略模板（均线交叉、RSI 超买超卖、网格交易、马丁格尔等）
- **自定义策略**：Python/JS 在线编辑器 + 代码模板
- **策略回测**：基于历史 K 线数据的回测引擎，显示收益曲线、最大回撤、夏普比率
- **一键部署**：策略 → 选择交易所 → 设置参数 → 运行
- 🆕 **AI 策略生成**：自然语言描述交易想法 → AI 自动生成可执行策略代码
- 🆕 **AI 策略优化**：贝叶斯参数优化 + LLM 逻辑变异 + A/B 测试自动进化

### 2. 🔗 交易所接入
- **币安（Binance）**：通过 REST API + WebSocket 实时行情
- **MT4/MT5**：通过 MetaTrader Manager API / gRPC Bridge 连接
- **统一抽象层**：策略代码不感知底层交易所，一套策略多平台运行

### 3. 📈 实时监控
- 策略运行状态面板（持仓、盈亏、信号触发记录）
- 实时 K 线图表（TradingView 嵌入或自研轻量图表）
- 多账户聚合视图

### 4. 🛡️ 风控系统
- 单笔/总仓位止损止盈
- 日最大亏损限制（熔断机制）
- 异常波动自动暂停策略
- API 权限最小化（只读 + 交易，禁止提币）

### 5. 🔔 消息通知
- 交易信号推送（开仓/平仓/止损触发）
- 策略异常告警（断线、API 限频、余额不足）
- 每日/每周收益报告

### 6. 📋 数据分析
- 收益曲线 & 历史交易记录
- 策略对比分析
- 风险指标（最大回撤、胜率、盈亏比）

### 7. 🧠 AI 引擎 🆕
- **AI 交易助手**：对话式交互，问"为什么亏了""市场怎么了"，AI 实时回答
- **市场情报分析**：新闻、社交媒体、链上数据的多源实时语义分析
- **策略自进化**：AI 分析交易表现 → 生成优化变体 → 回测验证 → A/B 测试 → 自动升级
- **风险预判**：宏观事件、资金费率、链上异动的综合风险评分
- **多模型混合**：DeepSeek-Coder（代码）+ Qwen（分析）+ 本地微调模型（风控）

### 技术栈选型

| 层级 | 技术 | 理由 |
|------|------|------|
| **移动端** | Flutter (Dart) | 跨平台、UI 表现力强、生态成熟 |
| **后端** | Go (Gin/Fiber) | 高并发、低延迟、部署简单 |
| **策略引擎** | Python (独立进程) | 量化生态丰富 (pandas, ta-lib, backtrader) |
| **AI 引擎** | Python + LangChain | LLM 编排、Agent 框架成熟 |
| **LLM** | DeepSeek + Qwen + Llama | 多模型混合，按任务路由 |
| **数据库** | PostgreSQL + TimescaleDB | 关系型 + 时序数据一体化 |
| **缓存** | Redis | 实时行情缓存、会话管理 |
| **消息队列** | NATS | 轻量、低延迟、适合交易场景 |
| **MT4/5 桥接** | MetaTrader gRPC Bridge | 官方推荐的外部连接方式 |
| **部署** | Docker + K8s | 可扩展、易维护 |

## 关键流程

### 策略执行流程
```
用户创建策略 → 参数配置 → 回测验证 → 部署上线
                                        │
                        ┌───────────────┼───────────────┐
                        ▼               ▼               ▼
                   行情数据接收     策略信号计算      订单执行
                   (WebSocket)    (Python 引擎)    (交易所 API)
                        │               │               │
                        └───────────────┼───────────────┘
                                        ▼
                               风控检查 → 下单 → 推送通知
```

### MT4/5 连接方案
```
手机 App ──HTTPS──▶ 后端服务 ──gRPC──▶ MT Bridge EA
                                            │
                                            ▼
                                      MT4/MT5 终端
                                      (需在 VPS 上运行)
```

> **重要说明**：MT4/MT5 没有原生的移动端 API。方案是：
> 1. 在 VPS/PC 上运行 MetaTrader 终端
> 2. 安装一个 Expert Advisor (EA) 作为 gRPC/WebSocket 桥接
> 3. 手机 App 通过后端服务与这个桥接通信

## 安全设计

### API 密钥安全
- 用户的交易所 API Key 使用 AES-256-GCM 加密存储
- 密钥仅在后端内存中解密使用，不落盘明文
- 支持 API Key 权限校验（禁止提币权限的 Key）

### 账户安全
- JWT + Refresh Token 双令牌认证
- 生物识别（指纹/Face ID）登录
- 敏感操作（删除策略、修改风控）二次验证

### 网络安全
- 全链路 HTTPS + TLS 1.3
- WebSocket 连接使用 wss://
- API 请求签名验证（防篡改）
